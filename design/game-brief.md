# Game Brief: 황동골 철도 회사 (가제, 구 "철환 장갑열차")

**One-sentence pitch:** 고리 선로를 도는 증기 열차 회사를 경영해, 폐허에서 시작한 마을 황동골을 돈·화물·생산·주민으로 키워 도시로 만드는 스팀펑크 경영 시뮬레이션.

> 2026-11-02 04:20 사용자 결정: "완전 경영 시뮬레이션 쪽으로 싹 다." 전투·방어·장비·고철 파밍은 전부 제거(039)하고, 아래 경영 루프로 전환한다. 타일 배치로 건물을 짓는 조작과 NPC·도감·폐허 연출은 그대로 가져간다.

## Core loop
- **열차는 자동으로 고리 선로를 돈다.** 거점(황동골) 1곳과 휴식지 3곳(잿더미 쉼터·녹슨 다리·급수탑 쉼터)이 원을 이루고, 거점에 돌아오면 1바퀴(= 경영의 한 턴). 선로는 끊기지 않는다.
- **돈(마르크).** 수입은 승객 운임, 화물 판매, 건물 생산물 판매. 지출은 열차 유지비, 건물 유지비, 주민 임금. 바퀴마다 장부에 정산된다. 잔고가 0 아래로 세 바퀴 연속이면 파산 = 패배.
- **휴식지는 시장이다.** 휴식지마다 품목별 수요·공급과 가격이 있고(데이터, 거래로 오르내림), 열차가 정차하면 거래 패널에서 화물칸 용량만큼 사고판다. 품목은 스팀펑크 상품 6종: 석탄·철·부품·식량·유리·황동. 휴식지 이벤트(039)는 경제 이벤트로 바뀐다: 가격 급등·급락, 상인(설계도 판매), 파업, 폭풍(유지비 증가), 승객 몰림.
- **거점 내부는 그대로 타일 배치**(선로 위·아래 각 4×12칸, 드래그 앤 드롭·핫바 1~9·고스트, 묶음형·혼합 묶음형·패턴형 레시피, 완성된 건물은 칸 고정, 되돌리기·철거). 다만 **타일에는 값이 있고**(돈) 완성된 건물은 **생산 건물**이다: 입력 품목 → 출력 품목(바퀴당), 필요한 노동자 수, 유지비. 예: 석탄 야적장 → 석탄; 보일러실: 석탄 → 증기(마을 동력, 품목 아님 — 공장 가동 조건); 공방: 철 + 증기 → 부품; 온실: 물탱크 연결 → 식량; 가스등 거리 → 만족도; 막사·침상 → 주거. 생산물은 거점 창고에 쌓이고, 열차에 실어 휴식지에 팔거나 마을이 소비한다. 레시피는 지금처럼 시작 3개에서 NPC·상인·발견으로 도감에 쌓인다.
- **주민과 노동.** 고유 NPC는 지금처럼 승객으로 와서 조건이 맞으면 합류하고(집 = 자기 종류의 건물, 대화 CG), 거기에 더해 **일반 주민**이 주거·식량·만족도가 충족되면 바퀴마다 늘어난다("주민 N명"). 건물은 필요한 노동자가 배치돼야 돌아가고(자동 배치, 부족하면 가동 중단), 남는 주민은 실업으로 만족도를 깎는다. 만족도 = 주거·식량·빛(가스등)·일자리.
- **성장과 해금.** 마을 등급은 폐허 → 정착촌 → 마을 → 도시(인구·번영 기준, 데이터). 등급이 오르면 새 레시피, 열차 업그레이드(화물칸·승객칸 추가, 기관 속도), 새 휴식지·거점 개통(선로 확장 비용)이 열린다. 폐허 연출(웅덩이·잡초·모닥불)은 등급이 오르면 걷힌다.

## Player goal & fail state — what "working" looks like
- 목표: 20바퀴 안에 황동골을 **도시** 등급(인구·번영 기준값, 데이터)으로 키운다. 도달하면 승리, 기한이 지나면 등급에 따라 부분 성공, 파산(잔고 < 0 세 바퀴 연속)이면 그 자리에서 패배. 결과 화면에 재무 요약(총수입·총지출·최고 잔고·인구)과 다시 시작.
- 한 바퀴의 플레이: 거점에서 타일을 사서 건물을 짓고 창고의 생산물을 열차에 싣는다 → 출발(자동) → 휴식지마다 거래·이벤트 → 거점 복귀 정산(장부 토스트: "+운임 12 +판매 30 −유지비 18 = +24").

## MVP — what must exist to be the game
- 경제 기반: 돈(마르크)·품목 6종·휴식지 시장(가격·수요·공급 데이터, 거래 변동)·열차 화물칸 용량·정차 거래 패널·승객 운임·열차/건물 유지비·바퀴 정산 장부·파산 패배
- 생산 건물: 서식지 레시피(19종)를 생산 건물 데이터로(입력/출력/노동자/유지비), 거점 창고, 타일 비용, 창고 → 열차 적재
- 주민·노동·만족도·마을 등급: 일반 주민 증가, 노동자 자동 배치와 가동 조건, 만족도 4요소, 등급과 해금 표
- 열차 업그레이드와 선로 확장: 화물칸·승객칸·기관 구매, 새 휴식지/거점 개통(데이터로 확장)
- 경영 HUD: 상단 잔고·바퀴·인구·만족도, 거래 패널, 건물 정보(생산·노동자·유지비), 장부 화면, 목표 표시, 결과 재무 요약, 경제 이벤트
- (유지) 거점 내부 타일 배치·레시피·도감, 고유 NPC 승객·합류·대화 CG, 폐허 연출, 한국어 UGUI

**Who it's for / what they feel:** 한 판 30~40분, 장부가 흑자로 돌아서는 순간과 마을이 등급을 올리는 순간의 성취감을 즐기는 경영 게임 팬.

**Art & audio direction:** 탑뷰 2D 도트, 황동·증기 톤, 게임 내 텍스트는 한국어. 기계음 중심의 낮은 BGM. 환경 아트 기준(2026-11-01, 사용자 참고 이미지 "Top-down Steampunk 2D Game Environment Art"): 바닥은 보라빛이 도는 회색 돌바닥(#65575c 계열, 줄눈 #3a2e44)에 이끼·먼지 점이 섞이고, 건물은 어두운 적갈색 벽(#54303a·#513647)과 슬레이트 지붕(#3a3f4a), 구리·황동 장식(#995636·#d6a053), 리벳 박힌 파이프와 톱니, 굴뚝에서 피어오르는 연기(#f2decd), 따뜻한 호박색 창 불빛(#ffcf6a)과 가스등 광륜, 나무 상자·배럴, 청록 물(#5b7983), 드문드문 초록 관목(#4f7a3a). 짙은 외곽선(#322438)과 2~3단 명암의 도트 질감. 모든 스프라이트는 64px(1칸 = 64px, PPU 64)로 그린다. 타일·건물은 스팀펑크 마을 요소만(자연 타일 없음; 폐허 연출의 물·풀은 환경 장식).

**편집 규칙:** 고정 배치는 씬의 프리팹 인스턴스, 동적 조각은 프리팹 인스턴스화. 런타임 코드 생성 배치 금지. UI는 UGUI다(사용자 최종 결정 2026-11-01 20:20). 캔버스 프리팹 `MainCanvas` 하나를 씬에 두고, 화면(상황)마다 프리팹 하나(`Assets/Prefabs/UI/Screens/`)를 자식 인스턴스로 두어 켜고 끈다. 스크립트는 인스펙터 참조로 바인딩만 하고 UI를 코드로 만들지 않는다. 글꼴은 TextMeshPro(NotoSansKR SDF), 색·크기는 `UiTheme` 데이터. 디자이너는 Scene 뷰·프리팹 모드에서 고친다.

**개발 규칙:** 스펙 우선(SDD). 브리프와 스토리를 먼저 고치고 구현한다. 자동 테스트는 두지 않으며(AX 기반), 검증은 열린 편집기의 파이프라인(컴파일·생성기·씬 저장)이고 화면은 사용자가 편집기에서 본다(캡처 없음, 2026-11-02 03:30). 모든 수치는 데이터. 판단이 애매하면 `.claude/agents/*.md`의 역할 정의를 따른다.

**Reference game:** 포코피아(타일을 이어 붙여 건물을 짓고 개체를 불러오는 조작) + 트랜스포트 타이쿤/레일로드 타이쿤(노선 위 화물 거래와 장부). 규모는 거점 1곳·휴식지 3곳의 고리로 줄인다.
