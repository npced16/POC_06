# Game Brief: 철환(鐵環) 장갑열차 (가제)

**One-sentence pitch:** 고리형 선로를 도는 장갑열차를 몰며 네 거점을 지키고 키워, 서식지 조합으로 고유 NPC를 불러 모으는 스팀펑크 방어 경영 게임.

## Core loop
- 열차가 고리형 선로를 한 칸씩 이동해 경유지 이벤트 또는 전투를 치른다. 결과는 다음 거점의 번영에 영향을 준다(자원·제작 시스템은 당분간 없음).
- 거점에 정차하면 내부 탑뷰(선로 위·아래 각 4×12칸, 바닥에 보이는 칸은 전부 놓을 수 있다)로 들어가, 인벤토리의 타일·아이템을 드래그 앤 드롭이나 핫바(1~9 키, 고스트 미리보기)로 칸에 배치한다. 서식지는 두 종류로 완성된다. 묶음형은 같은 타일이 필요한 칸 수(3·4·9 등)만큼 상하좌우로 이어지면(ㅁ·일자·L 등 모양 무관) 완성되고, 패턴형은 타일 배열 템플릿(예: 보일러-증기관-톱니장치 = 증기 기관실)이 회전·거울상 변형 중 하나로 들어맞으면 완성된다(톱니장치-증기관-보일러는 인정, 증기관-보일러-톱니장치처럼 순서가 다르면 불인정). 타일과 서식지는 모두 스팀펑크 마을을 이루는 요소(보일러·증기관·톱니장치·가스등·석탄더미·철골·벽돌길·물탱크·온실유리·침상·작업대·전신주·굴뚝)로만 만들며, 풀·물·불 같은 자연 타일은 쓰지 않는다. 서식지 종류는 많고 모두 데이터다. 같은 타일만 모으는 종류는 서너 개뿐이고, 대부분은 타일 두세 종을 섞어 이어 붙이는 혼합 묶음이나 패턴이며 크기도 2~9칸으로 제각각이다. 서식지의 완성 조건(레시피)은 처음에 몇 개만 알고 시작하고, 선로를 돌며(바퀴를 채울 때, 경유지 이벤트·전투 승리, 모르는 채로 우연히 완성했을 때) 하나씩 얻어 도감에 쌓인다. 도감은 19종을 모두 보여 주되 아직 모르는 것은 "???"로 가린다. 방어시설도 같은 방식으로 칸에 놓는다.
- 서식지가 완성되면 이벤트 플래그가 켜지고, 다음 방문 때 확률로 고유 NPC가 합류한다. 합류한 NPC는 자기 종류의 서식지를 집으로 배정받아 그 곁에서 지내고, 빈 손으로 클릭하면 대화 패널(대사 순환·격려 같은 상호작용)이 열린다.
- 거점은 폐허에서 시작해 복구 중·정착으로 올라가고, 방치하면 다시 붕괴한다. 붕괴한 거점도 선로에 남고, 열차는 그 거점도 계속 들르며 순환한다.

## Player goal & fail state — what "working" looks like
- 목표: 폐허로 시작하는 네 거점에 서식지를 여러 종류 예쁘게 배치해 복구하고, 가능한 한 많이 정착시킨다.
- 실패: 한 번 정착했던 거점이 모두 붕괴하거나, 정해진 바퀴 수 안에 한 곳도 정착시키지 못하면 런이 끝난다. 선로는 어떤 경우에도 끊기거나 떨어져 나가지 않는다.

## MVP — what must exist to be the game
- 거점 4곳과 경유지로 이루어진 고리형 선로 위의 열차 이동
- 경유지 이벤트 및 간단한 전투 1종
- 거점 내부 탑뷰(위·아래 4×12칸)에서 드래그 앤 드롭·핫바(1~9, 고스트)로 타일·아이템을 배치하고, 묶음형(같은 타일 N칸 연결, 모양 무관)·혼합 묶음형(정해진 타일 집합이 연결되고 타일별 최소 수를 채움, 모양 무관)·패턴형(타일 배열 템플릿, 회전·거울상 허용, 순서 바꿈 불허)으로 서식지가 완성되어 이벤트 플래그를 켜는 시스템. 서식지 종류 카탈로그는 데이터(같은 타일 묶음 4종·혼합 묶음 9종·패턴형 6종 = 19종, 크기 2~9칸). 레시피는 돌면서 얻고 도감에 쌓인다. 타일·아이템·시설은 핫바에서 무제한으로 꺼내 놓는다(자원·제작 없음)
- 고유 NPC 풀과 확률 합류 (한 NPC는 한 번만 등장), 합류한 NPC는 거점 내부에 거주
- 방어시설 건설 2~3종 (내부의 시설 부지에)
- 거점 상태(폐허 → 복구 중 → 정착 → 붕괴)와 번영 수치, 정착했던 거점이 모두 붕괴하거나 기한 안에 정착 0이면 패배
- 한국어 HUD와 탑뷰 표현 (선로 화면, 거점 내부 화면, 핫바·번영·단계·현재 위치)

## Out of scope — not building this
- 싱글플레이 전용. 멀티플레이, 세이브 슬롯 여러 개, 스토리 컷신 없음
- MVP는 거점 4곳으로 고정. 거점 추가는 데이터로 확장할 수 있게 설계하되 MVP에서는 만들지 않음
- 분기하는 선로, NPC 대화 트리 (한 줄 대사만)
- 자원(석탄·고철·물·곡물)과 제작 시스템은 당분간 없음. 자원 슬롯 방식(002), 잔해 조사·태그 합산 방식(012·013 초기), 자원 제작(013)은 코드로 보존하되 비활성. 순수 장식물의 번영 보너스는 소량으로만

## Build order
1. 고리 이동과 정차 (열차가 거점을 도는 뼈대)
2. 서식지 조합 판정과 NPC 확률 합류 (가장 검증이 필요한 부분)
3. 거점 번성/쇠락 수치와 폐허 전환, 패배 조건
4. 경유지 전투와 방어시설
5. HUD와 연출
6. 거점 내부 탑뷰: 잔해 조사 → 아이템·태그 서식지 → 거점 단계와 새 패배 규칙 (스토리 012~014)
7. 배치 개편: 조사 제거, 드래그 앤 드롭·핫바 고스트 배치, 연결된 칸 모양으로 완성되는 다종 서식지 카탈로그 (스토리 015~016)
8. 보이는 것 다듬기: NPC 집·대화(017), UI 문서를 씬 프리팹으로(018), 참고 이미지 기반 탑뷰 스팀펑크 환경 아트 적용(019), UGUI 화면 프리팹 전환(022)
9. 서식지 다양화: 혼합 묶음·크기 다양화 카탈로그 재설계와 설치칸 확장(020), 레시피 해금과 도감(021)

**Who it's for / what they feel:** 한 판 20~30분, 거점을 키우는 재미와 무너질까 하는 긴장을 함께 즐기는 경영 게임 팬.

**Art & audio direction:** 탑뷰 2D 도트, 황동·증기 톤, 게임 내 텍스트는 한국어. 기계음 중심의 낮은 BGM. 환경 아트 기준(2026-11-01, 사용자 참고 이미지 "Top-down Steampunk 2D Game Environment Art"): 바닥은 보라빛이 도는 회색 돌바닥(#65575c 계열, 줄눈 #3a2e44)에 이끼·먼지 점이 섞이고, 건물은 어두운 적갈색 벽(#54303a·#513647)과 슬레이트 지붕(#3a3f4a), 구리·황동 장식(#995636·#d6a053), 리벳 박힌 파이프와 톱니, 굴뚝에서 피어오르는 연기(#f2decd), 따뜻한 호박색 창 불빛(#ffcf6a)과 가스등 광륜, 나무 상자·배럴, 청록 물(#5b7983), 드문드문 초록 관목(#4f7a3a). 짙은 외곽선(#322438)과 2~3단 명암의 도트 질감. 모든 스프라이트는 64px(1칸 = 64px, PPU 64)로 그린다.

**편집 규칙:** 고정 배치는 씬의 프리팹 인스턴스, 동적 조각은 프리팹 인스턴스화. 런타임 코드 생성 배치 금지. UI는 UGUI다(사용자 최종 결정 2026-11-01 20:20, UI Toolkit 전면 교체). 캔버스 프리팹 `MainCanvas` 하나를 씬에 두고, 화면(상황)마다 프리팹 하나(`Assets/Prefabs/UI/Screens/`)를 자식 인스턴스로 두어 켜고 끈다. 스크립트는 인스펙터 참조로 바인딩만 하고 UI를 코드로 만들지 않는다. 글꼴은 TextMeshPro(NotoSansKR SDF), 색·크기는 `UiTheme` 데이터. 디자이너는 Scene 뷰·프리팹 모드에서 고친다.

**개발 규칙:** 스펙 우선(SDD). 브리프와 스토리를 먼저 고치고 구현한다. 자동 테스트는 두지 않으며(AX 기반), 증거는 열린 편집기의 컴파일 확인과 스크린샷이다. 판단이 애매하면 `.claude/agents/*.md`의 역할 정의를 따른다.

**Reference game:** 포코피아 — 타일을 이어 붙여 서식지를 만들고 개체를 불러오는 부분을 가져오되, 규모는 거점 4곳(각 3×6 두 구역)으로 줄인다. 배치 조작은 마인크래프트식 핫바(1~9)와 고스트 미리보기.
