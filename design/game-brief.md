# Game Brief: 황동골 철도 회사 (가제, 구 "철환 장갑열차")

**One-sentence pitch:** 고리 선로를 도는 증기 열차로 승객을 실어 나르며, 폐허에서 시작한 마을 황동골에 타일을 이어 붙여 건물을 짓고 주민을 불러 모아 도시로 키우는 가벼운 스팀펑크 마을 경영 게임.

> 2026-11-02 06:40 사용자 결정("게임이 이상하게 가는데?" → "가볍게 — 마을 키우기만"): 교역·화물·시장·생산 체인·창고·노동·만족도는 빼고(040·041의 해당 코드는 `archive/economy-trade-2026-11-02/` 보관, 스토리 045), 전투도 없다(039). 남는 것은 배치·건물·주민·NPC·돈·번영·등급.

## Core loop
- **열차는 자동으로 고리 선로를 돈다.** 거점 황동골 1곳과 휴식지 3곳(잿더미 쉼터·녹슨 다리·급수탑 쉼터)이 원을 이루고, 거점에 돌아오면 1바퀴(= 한 턴). 휴식지마다 이벤트가 하나씩 일어나고(상인·합승·폭풍·창고·휴식·선로 보수…), 고유 NPC가 승객으로 올라타 황동골에 내린다.
- **거점 내부는 타일 배치.** 선로 위·아래 각 4×12칸에 드래그 앤 드롭·핫바(1~9, 고스트)로 타일을 놓고, 묶음형·혼합 묶음형·패턴형 레시피(19종, 도감)가 맞으면 건물이 완성된다(완성된 건물은 칸 고정, 되돌리기·철거). 타일에는 값이 있다(4~12마르크, 환급 전액).
- **돈(마르크).** 바퀴마다 정산: +완성 건물의 수입 합 +승객 운임. 유지비는 없다(사용자 결정 2026-11-02 09:30 — 나중에 마을별 멸망 시나리오로 긴장을 만든다). 돈은 타일을 사는 데 쓴다. 파산은 없다(돈이 없으면 못 지을 뿐).
- **주민.** 시작 3명. 바퀴마다 주거(막사·침상 건물)가 남으면 늘고(가스등이 넉넉하면 더), 주거가 모자라면 줄어든다. 고유 NPC는 지금처럼 조건이 맞으면 합류해 자기 건물 곁에 산다(대화 CG). 주민과 NPC는 번영을 올린다.
- **마을 등급.** 폐허 → 정착촌 → 마을 → 도시(주민·번영 기준). 등급이 오르면 새 레시피가 열리고 폐허 연출이 걷힌다. 주민과 등급은 마을마다 따로 센다.
- **선로가 열린다.** 지금은 황동골 한 마을만 키우는 느낌이지만, 황동골이 정착촌이 되면 "선로가 열렸습니다" 연출과 함께 고리 위 폐쇄된 선로가 열려 두 번째 마을 잿골이 나타나고, 열차는 거기도 정차한다(잿골도 배치·주민·등급이 따로 돌아간다). 나중에는 여러 마을로 확장해 여러 곳을 돌고, 마을마다 멸망 시나리오를 둔다(스토리 048 이후).

## Player goal & fail state — what "working" looks like
- 목표: 20바퀴 안에 황동골을 **도시**로. 도달하면 승리, 기한이 지나면 등급별 부분 성공, 주민이 1명으로 떨어지고 번영이 바닥이면 붕괴 = 패배. 결과 화면에 총수입·총지출·최종 등급.
- 한 바퀴의 플레이: 거점에서 돈으로 타일을 사 건물을 완성한다 → 출발(자동) → 휴식지 이벤트·승객 → 거점 복귀 정산 토스트("바퀴 N 정산: +건물 24 +운임 8 = +32", 유지비 없음) → 주민·등급 갱신.

## MVP — what must exist to be the game
- 원형 선로 이동·휴식지 이벤트·승객(기존)
- 거점 내부 타일 배치·레시피·도감·건물·되돌리기·철거(기존) + 타일 가격
- 돈·바퀴 정산(건물 수입·운임, 유지비 없음 — 048)·정산 토스트
- 주민 증감(주거·빛)과 마을 등급·레시피 해금·런 결과
- HUD: 상단 잔고·주민, 거점 상태줄 등급과 다음 조건, 등급 배너, 결과 재무 줄(UGUI, codex, 부족분은 Claude — 2026-11-02 08:05 codex에서 이관)
- (유지) 고유 NPC·대화 CG, 폐허 연출, 한국어

**Who it's for / what they feel:** 한 판 30~40분, 돈을 모아 건물을 올리는 순간과 마을이 등급을 올리는 순간의 성취감을 즐기는 경영 게임 팬.

**Art & audio direction:** 탑뷰 2D 도트, 황동·증기 톤, 게임 내 텍스트는 한국어. 기계음 중심의 낮은 BGM. 환경 아트 기준(2026-11-01, 사용자 참고 이미지 "Top-down Steampunk 2D Game Environment Art"): 바닥은 보라빛이 도는 회색 돌바닥(#65575c 계열, 줄눈 #3a2e44)에 이끼·먼지 점이 섞이고, 건물은 어두운 적갈색 벽(#54303a·#513647)과 슬레이트 지붕(#3a3f4a), 구리·황동 장식(#995636·#d6a053), 리벳 박힌 파이프와 톱니, 굴뚝에서 피어오르는 연기(#f2decd), 따뜻한 호박색 창 불빛(#ffcf6a)과 가스등 광륜, 나무 상자·배럴, 청록 물(#5b7983), 드문드문 초록 관목(#4f7a3a). 짙은 외곽선(#322438)과 2~3단 명암의 도트 질감. 모든 스프라이트는 64px(1칸 = 64px, PPU 64)로 그린다. 타일·건물은 스팀펑크 마을 요소만(자연 타일 없음; 폐허 연출의 물·풀은 환경 장식).

**편집 규칙:** 고정 배치는 씬의 프리팹 인스턴스, 동적 조각은 프리팹 인스턴스화. 런타임 코드 생성 배치 금지. UI는 UGUI다(사용자 최종 결정 2026-11-01 20:20). 캔버스 프리팹 `MainCanvas` 하나를 씬에 두고, 화면(상황)마다 프리팹 하나(`Assets/Prefabs/UI/Screens/`)를 자식 인스턴스로 두어 켜고 끈다. 스크립트는 인스펙터 참조로 바인딩만 하고 UI를 코드로 만들지 않는다. 글꼴은 TextMeshPro(NotoSansKR SDF), 색·크기는 `UiTheme` 데이터. 디자이너는 Scene 뷰·프리팹 모드에서 고친다.

**개발 규칙:** 스펙 우선(SDD). 브리프와 스토리를 먼저 고치고 구현한다. 자동 테스트는 두지 않으며(AX 기반), 검증은 열린 편집기의 파이프라인(컴파일·생성기·씬 저장)이고 화면은 사용자가 편집기에서 본다(캡처 없음, 2026-11-02 03:30). 모든 수치는 데이터. 판단이 애매하면 `.claude/agents/*.md`의 역할 정의를 따른다.

**Reference game:** 포코피아(타일을 이어 붙여 건물을 짓고 개체를 불러오는 조작) + 트랜스포트 타이쿤/레일로드 타이쿤(노선을 도는 열차와 정차지 성장 — 화물 거래·장부는 빼고). 규모는 황동골 1곳·휴식지 3곳의 고리에서 시작해 048부터 마을을 하나씩 연다.
