# 황동골 철도 회사 (가제)

고리 선로를 도는 증기 열차와 폐허 마을 황동골을 키우는 가벼운 스팀펑크 마을 경영 게임. Unity 6.3 LTS(6000.3.27f1), C#, 탑뷰 2D, UGUI.

- 게임 컨셉·규칙·다음 할 일: [`design/game-brief.md`](design/game-brief.md)
- 작업 규칙(코드 스타일, 씬·프리팹, 편집기 브리지 검증): [`AGENTS.md`](AGENTS.md)
- 플레이 씬: `Assets/Scenes/Main.unity`
- 편집기 제어: `tools/bridge/` (열린 Unity 편집기를 파일 큐로 제어)
- 보관한 옛 기능: `archive/`, 작업 기록: `production/`
