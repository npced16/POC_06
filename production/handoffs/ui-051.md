# UI 작업 051: 페이즈 배너, 중간역 사건 창, 핫바 재고 배지 (codex)

규칙: `production/handoffs/codex-ui-charter.md`. 스펙: `production/epics/iron-ring-train/story-051-phase-loop-events.md`. git 조작 금지, 씬 YAML 직접 편집 금지(프리팹은 편집기 빌더로). **050 UI(ui-050.md)를 먼저 끝낸 뒤** 진행.

## UI 수용 기준
1. **페이즈 배너**: 건설 페이즈 진입 시 중앙 배너 "건설 페이즈 — 바퀴 N"(2초), 순환 페이즈 진입 시 "순환 페이즈". 상단 바에 작은 페이즈 표시(건설/순환). 출발 버튼은 건설 페이즈에서만 보임.
2. **사건 창**: 휴식지 정차 시 화면 가운데 창 — 제목(Heading), 상황 글(Normal, 2~3줄), 선택지 버튼 2~3개(세로), 선택 뒤 버튼 대신 결과 한 줄 + [계속]. 뒤 화면 입력 막음. 1280×720에서 선택지 글자가 잘리지 않게.
3. **핫바 재고 배지**: 재고가 있는 타일 슬롯에 "×N" 배지, 가격 줄은 "재고 N"으로. 재고 0이면 기존 가격.
4. 문구 `ko.json` 끝에 append.
