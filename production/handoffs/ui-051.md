# UI 작업 051: 페이즈 배너, 중간역 사건 창, 핫바 재고 배지 (codex)

규칙: `production/handoffs/codex-ui-charter.md`. 스펙: `production/epics/iron-ring-train/story-051-phase-loop-events.md`. git 조작 금지, 씬 YAML 직접 편집 금지(프리팹은 편집기 빌더로). **050 UI(ui-050.md)를 먼저 끝낸 뒤** 진행.

## UI 수용 기준
1. **페이즈 배너**: 건설 페이즈 진입 시 중앙 배너 "건설 페이즈 — 바퀴 N"(2초), 순환 페이즈 진입 시 "순환 페이즈". 상단 바에 작은 페이즈 표시(건설/순환). 출발 버튼은 건설 페이즈에서만 보임.
2. **사건 창**: 휴식지 정차 시 화면 가운데 창 — 제목(Heading), 상황 글(Normal, 2~3줄), 선택지 버튼 2~3개(세로), 선택 뒤 버튼 대신 결과 한 줄 + [계속]. 뒤 화면 입력 막음. 1280×720에서 선택지 글자가 잘리지 않게.
3. **핫바 재고 배지**: 재고가 있는 타일 슬롯에 "×N" 배지, 가격 줄은 "재고 N"으로. 재고 0이면 기존 가격.
4. 문구 `ko.json` 끝에 append.

## 로직 API (Claude gameplay 에이전트가 채움)

작성: Claude gameplay, 2026-11-02. 계약은 `Assets/Scripts/Contracts/IronRingContracts.cs` 끝 "스토리 051" 절(append-only). 서비스는 Composing에서 등록되므로 **Ready 이후** `GameServices.Get<T>()`로 얻는다(설치 `IronRing.Track.LoopInstaller`).

### 1. 페이즈 — `IPhaseLoop`
| 멤버 | 뜻 |
|---|---|
| `LoopPhase Phase` | `Build`(거점 hub-1 정차) / `Circulate`(출발 ~ 거점 복귀) |
| `int Lap` | 바퀴 번호, **1부터**. 건설 N → 순환 N → 복귀하면 건설 N+1 |
| `bool CanDepart` | 출발 버튼 표시 조건. 역(거점 또는 열린 다른 마을)에 서 있고 사건 창이 없을 때 true. 휴식지·이동 중엔 false |
| `void Depart()` | 출발(기존 HUD 출발 버튼이 이걸 부르면 됨. `ITrackRuntime.Depart` 직접 호출도 페이즈가 따라간다) |
| `event Action<LoopPhase,int> PhaseChanged` | (새 페이즈, 바퀴). 시작 시점(Build, 1)은 이벤트가 없으니 Ready에서 `Phase`/`Lap`을 직접 읽어 배너를 그릴 것 |

배너 문구: `loop_phase_build`("건설 페이즈 — 바퀴 {0}", {0}=Lap), `loop_phase_circulate`("순환 페이즈"). 상단 바 짧은 표시: `loop_phase_short_build`("건설"), `loop_phase_short_circulate`("순환").
순환 중 열린 다른 마을(잿골 개통 후)에 서면 `Phase`는 계속 `Circulate`이고 `CanDepart`가 true → 출발 버튼은 `CanDepart`로만 판단하면 된다.

### 2. 중간역 사건 — `IRestEvents`
흐름: 휴식지 도착 → 열차 정지(hold `"rest-event"`) → `EventStarted` → 플레이어가 `Choose(i)` → 효과 적용 → `EventResolved` → `Continue()`([계속]) → `EventClosed` → (지연 효과가 있으면 그 초만큼 더 서 있다가) 출발.
| 멤버 | 뜻 |
|---|---|
| `bool IsActive` | 창을 띄워야 하는 동안 true(선택 전 + 결과 표시 중) |
| `string EventId`, `string NodeId` | 사건 id, 휴식지 id |
| `string Title`, `string Text` | 제목 / 상황 글(이미 한국어로 해석됨) |
| `IReadOnlyList<string> Choices` | 선택지 문구 2~3개(한국어) |
| `bool IsChoiceAvailable(int i)` / `string UnavailableReason(int i)` | 돈이 드는 선택지는 잔고가 모자라면 false + "마르크 부족"(`rest_choice_no_money`) → 버튼 비활성 + 이유 표시 |
| `bool HasResolved`, `int ChosenIndex` | 골랐는지, 고른 번호(-1 = 아직) |
| `string ResultText` | 결과 한 줄(확률 선택지가 실패하면 실패 문구) |
| `string ResultDetail` | 실제 얻고 잃은 것 요약(예: "석탄더미 ×3 · 보일러 ×1 · −10마르크"), 없으면 "". 결과 줄 아래 작게 |
| `bool Choose(int i)` | 선택. 활성 사건 없음/이미 고름/불가면 false |
| `void Continue()` | [계속]. 선택 전이면 무시 |
| `event Action EventStarted / EventResolved / EventClosed` | 창 열기 / 버튼 → 결과 줄+[계속] 전환 / 창 닫기 |

[계속] 문구: `loop_continue`("계속"). 자동 진행: `Assets/Scripts/Track/Resources/Track/RestEvents.json`의 `_autoContinueSeconds`(기본 4초, 결과 표시 뒤 저절로 Continue)·`_autoChooseSeconds`(기본 0 = 끔, UI가 없을 때 임시로 켜면 첫 고를 수 있는 선택지를 자동 선택).
**옛 휴식지 이벤트 표시와 겹침 주의:** `IWaypointResolver.EncounterStarted/EncounterEnded`와 `IEncounterPresentationSource`(옛 자동 이벤트 제목)는 여전히 나지만 효과는 모두 꺼졌다(`Story005Encounters.json` `_effect: "none"`). HUD(TopBar/HubPanel)에 옛 이벤트 제목을 띄우는 곳이 있으면 숨기고 새 사건 창만 보이게 할 것.

### 3. 타일 재고 — `ITileStock`
| 멤버 | 뜻 |
|---|---|
| `int CountOf(string itemId)` | 재고 수(0이면 기존 가격 표시) |
| `IReadOnlyDictionary<string,int> Snapshot()` | 재고 있는 품목 전부 |
| `event Action<string,int> Changed` | (품목, 새 수) → 핫바 배지 다시 그리기 |
| `Add` / `TryTake` | 로직용(사건 효과·배치 결제). UI는 읽기만 |

배지: `stock_badge`("×{0}"), 가격 줄: `stock_price`("재고 {0}"). 재고는 잠긴 타일을 갖지 않는다(사건이 열린 타일만 준다).
**결제 규칙(ItemPlacement):** 놓을 때 재고가 있으면 재고 1을 쓰고 돈은 안 낸다(잔고가 0이어도 놓을 수 있음 → `IItemPlacement.CanPlace`가 이미 반영). 없으면 기존처럼 돈. **회수:** 재고로 놓은 칸은 재고로 1 되돌리고 환급 없음, 돈으로 산 칸은 기존 환급. (`ItemPlacement.IsStockPaid(hubId, cell)`로 조회 가능.)

### 4. 승객
`passenger` 효과는 `IPassengers.TryBoard(npc, 휴식지, force:true)`(지정 NPC) 또는 `IPassengers.TryBoardAny(휴식지)`(무작위)로 태운다 → 기존 `Boarded` 이벤트·승객 목록·거점 하차 규칙 그대로. 옛 "휴식지마다 확률 탑승"은 `RestEvents.json _disableAutoBoarding: true`로 꺼졌다(인내 바퀴가 지나 떠나는 규칙은 그대로).

### 5. 데모(캡처용)
`--loop-demo`: 보일러실 첫 완성(증기관·굴뚝 해금) → 출발 → 휴식지 3곳에서 `_demoQueue` 순서의 사건(석탄 상인 → 떠돌이 기술자 → 버려진 화물칸)이 뜨고 1.2초 뒤 첫 선택지 자동 선택, 1.5초 뒤 Continue → 거점 복귀(건설 바퀴 2) → 재고 석탄더미를 빈 칸에 배치. 사건 창 캡처는 각 휴식지 선택 전 1.2초 사이, 재고 배지는 복귀 직후.
