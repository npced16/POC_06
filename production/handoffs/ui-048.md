# UI 작업 048: 선로 개통 연출, 마을별 주민·등급 표시 (Claude ui-programmer)

규칙: `production/handoffs/codex-ui-charter.md`(담당은 Claude). 스펙: `production/epics/iron-ring-train/story-048-line-opens-second-village.md`.

## UI 수용 기준
1. **개통 연출**: `ILineOpener.HubOpened(hubId)`가 오면 중앙 배너 "선로가 열렸습니다 — 잿골"(2.5초, PhaseBanner 재사용) + 토스트 1회. 로직 토스트와 겹치면 HUD가 삼킴(`ToastScreen.Swallow`).
2. **상단 상태줄 "주민 N"**: 현재 마을(내부가 열린 거점, 아니면 열차가 선 거점, 아니면 황동골) 기준 `IPopulation.ResidentsAt(hubId)`. 마을 이름을 함께 "황동골 주민 4" 또는 아이콘 옆 작은 글씨.
3. **거점 상태줄·내부 제목·등급 배너**: 현재 마을 이름(황동골/잿골)과 그 마을의 등급·다음 조건(`ITownTier.TierAt/NextNeedsAt`). 목표 줄은 황동골 도시 고정.
4. **결과 화면**: 거점 줄에 열린 마을마다 "이름 · 등급 · 주민 N". 잠긴 마을은 표시하지 않음.
5. **정산 토스트**: 로직이 띄움(유지비 0이면 항목 생략) — UI 작업 없음.
6. 문구 `ko.json` 끝에 `ui_line_opened`, `ui_topbar_people_at` 등.

## 로직 API (Claude gameplay 에이전트가 채움)

모든 서비스는 `GameServices.Get<T>()`로 **Ready 이후** 얻는다. 계약은 `Assets/Scripts/Contracts/IronRingContracts.cs`(append-only, 새 멤버는 기본 구현이 있어 옛 가짜 구현도 컴파일된다).

### ILineOpener (새, EconomyInstaller가 Composing에서 등록)
- `bool IsOpen(string hubId)` — 선로에 없는 id·이미 열린 역은 true. 시작 시 `IsOpen("hub-2") == false`.
- `void Open(string hubId)` — 이미 열렸으면 무시. 로직이 황동골 정착촌 정산 때 부른다(UI가 부를 일 없음).
- `event Action<string> HubOpened` — 역이 열린 순간 한 번(`"hub-2"`). 배너는 여기에 건다.
- `IReadOnlyList<string> LockedHubIds` — 아직 잠긴 역(결과 화면에서 숨길 마을).
- 순서: 정산 토스트 → 등급 상승 토스트(`town_tier_up`) → `HubOpened` → 로직 토스트 `line_opened`("선로가 열렸습니다 — 잿골"). 배너와 겹치면 HUD가 `ToastScreen.Swallow`로 삼켜도 된다.

### "현재 마을" 규칙 (`CurrentHubId`, IPopulation·ITownTier 둘 다 같은 규칙)
1. 내부 화면이 열려 있으면 `IViewMode.InteriorHubId`
2. 아니면 열차가 선(IsHeld, Kind==Hub, 잠기지 않은) 역의 HubId
3. 아니면 `"hub-1"`(황동골). 세지 않는 마을(잠긴 hub-2)은 절대 나오지 않는다.

### IPopulation (확장)
- 옛 멤버 `Residents/Housing/Light` = **현재 마을** 값. `event Action Changed`는 어느 마을이 바뀌어도 온다(현재 마을이 바뀐 것은 `IViewMode.InteriorChanged`·`ITrackRuntime.Arrived`로 다시 읽을 것).
- `string CurrentHubId`, `int ResidentsAt(hubId)`, `int HousingAt(hubId)`, `int LightAt(hubId)` — 모르는/잠긴 마을은 0.

### ITownTier (확장)
- 옛 멤버 `Tier/TierId/TierName/IsMax/NextTier/NextResidentsNeed/NextProsperityNeed` = **현재 마을** 값. `UnlockedRecipeIds/UnlockedUpgradeIds` = 전역 누적.
- `event Action<int> TierChanged` — **황동골만**(옛 의미).
- `event Action<string,int> HubTierChanged` — 모든 마을(거점 id, 새 등급).
- `string CurrentHubId`, `int TierAt(hubId)`, `string TierNameAt(hubId)`, `bool NextNeedsAt(hubId, out int residents, out int prosperity)`(최고 등급이면 false, 0/0).
- 목표 줄: 항상 `TierAt("hub-1")` 기준 도시(승리 등급 3). 잿골은 보너스(승패에 무관, 잿골 붕괴 = 토스트만).

### 마을 이름
- 표시 이름은 `Strings.Get(hubId.Replace('-', '_'))` → `hub_1` "황동골", `hub_2` "잿골". (`HubProfiles.json` `_name`도 같다.)

### 결과 화면
- `IRunResult.HubCount`/`SettledCount`/`Hubs`는 **열린 마을만** 센다("정착 1/1" → 열리면 "2/2"). 마을 줄: `Hubs`의 HubId마다 `ITownTier.TierNameAt(id)` + `IPopulation.ResidentsAt(id)`.

### 로직 토스트 키(ko.json, 로직이 띄움)
- `econ_lap_head` "바퀴 {0} 정산:", `econ_part_buildings` "+건물 {0}", `econ_part_fare` "+운임 {0}", `econ_part_upkeep` "−유지비 {0}", `econ_lap_total` "= {0}" — 0인 항목 생략. 유지비는 0이라 안 나온다. (옛 `econ_lap_settled`는 남겨 둠, 미사용.)
- `line_opened` "선로가 열렸습니다 — {0}", `town_tier_up` "{0}이(가) {1} 등급이 되었습니다"(마을 이름 포함), `town_collapsed`(황동골), `town_collapsed_bonus`(다른 마을).
- 지도(Presentation, UI 아님): `map_line_closed` "폐쇄된 선로", `map_hub_ruin` "{0} · 폐허".

### 선로
- `ITrackNode.IsLocked`(기본 false). 잠긴 역은 `Arrived`가 오지 않는다(정차·내부·승객·이벤트 없음). 노드 순서: hub-1 → REST-1 → REST-2 → hub-2 → REST-3.
