# UI 작업 050: 조합 해금 표시 (codex)

규칙: `production/handoffs/codex-ui-charter.md`. 스펙: `production/epics/iron-ring-train/story-050-combo-unlocks.md`. git 조작 금지(코디네이터가 커밋). 씬 YAML 직접 편집 금지 — 프리팹은 편집기 빌더(`BuildMainCanvas.Generate`)로.

## UI 수용 기준
1. **핫바·팔레트**: 잠긴 타일은 보이지 않는다(시작 5종: 보일러·석탄더미·벽돌길·침상·작업대). 타일이 열리면 핫바의 빈 슬롯에 자동으로 들어가고, 9칸이 다 차 있으면 팔레트에만 추가. 새로 들어온 슬롯은 1.5초 반짝임(황동 테두리 깜박임).
2. **해금 토스트**: "새 타일: 증기관 · 굴뚝", "새 설계도: 배관 회랑"(로직이 띄우면 그대로, 겹치면 한 줄로 합쳐도 됨).
3. **도감**: 모르는 레시피는 "???" 카드(실루엣·어두운 톤). 재료 중 열린 타일은 이름·아이콘, 안 열린 재료는 "???". 알려진 레시피는 지금처럼.
4. **등급 배너/토스트**: "레시피 해금" 문구가 있으면 제거.
5. 문구는 `ko.json` 끝에 추가(append-only).

## 로직 API (Claude gameplay 에이전트가 채움)

작성: Claude gameplay, 2026-11-02 (스펙 b1228e6 반영 — 건물 15종, 새 해금표).

**잠금 판정은 한 곳: `IHabitatCodex.IsTileUnlocked(itemId)`.** `GameServices.Get<IHabitatCodex>()`로 얻는다(구현 `IronRing.Habitats.HabitatCodex`, `HabitatsInstaller.Codex`). 계약 `Assets/Scripts/Contracts/IronRingContracts.cs`의 `IHabitatCodex` 끝에 기본 구현과 함께 추가됨(옛 가짜 구현은 "잠금 없음"으로 그대로 컴파일).

| 멤버 | 뜻 |
|---|---|
| `bool IsTileUnlocked(string itemId)` | 놓을 수 있으면 true. 해금 데이터가 다루지 않는 아이템(장식 `decor`/`deco` 등)은 **늘 true** → 핫바·팔레트는 `IsTileUnlocked == false`인 것만 숨기면 됨. null → false |
| `IReadOnlyList<string> UnlockedTileIds` | 열린 타일(시작 5종 → 해금 순서). 다루는 타일만 |
| `IReadOnlyList<string> ManagedTileIds` | 해금 데이터가 다루는 타일 전부(13, "타일 n/13" 분모) |
| `bool HasBuilt(string typeId)` | 그 건물을 어느 마을에서든 한 번이라도 완성했는지 |
| `IReadOnlyList<string> TilesUnlockedBy(string typeId)` | 그 건물 첫 완성이 여는 타일(도감 카드에 "처음 지으면: 증기관 · 굴뚝" 같은 힌트용, 선택) |
| `string RequiredRecipeOf(string typeId)` | 알려지려면 먼저 지어야 할 건물(`power_house`←`engine_room`, `blast_furnace`←`iron_depot`), 없으면 null |
| `event Action<IReadOnlyList<string>, string> TileUnlocked` | (새 타일 id들, 원인 건물 id). 건물 **첫** 완성 때 1회, 새 타일이 있을 때만. → 핫바 빈 슬롯 자동 추가(9칸 차면 팔레트만) + 1.5초 반짝임 |
| `event Action<IReadOnlyList<string>, string> RecipesLearned` | (같은 순간 새로 알려진 레시피 id들, 원인 건물 id). 각 레시피의 `RecipeUnlocked(typeId, "combo")`가 모두 난 **뒤** 1회 |
| `event Action<string, string> RecipeUnlocked` (기존) | 레시피 하나가 알려질 때. 새 출처 `"combo"`(= `HabitatCodex.SOURCE_COMBO`). 기존 `"discover"`·`"board"`·`"teach"`·`"event"`는 그대로. 등급(`"tier"`)·바퀴(`"lap"`)·시작 레시피 해금은 더 일어나지 않음 |
| `bool IsUnlocked(string typeId)` (기존) | 레시피가 "알려짐"인지 → false면 도감 "???" 카드 |

이벤트 순서(같은 프레임): `TileUnlocked` → `RecipeUnlocked`×N(source "combo") → `RecipesLearned`.

**토스트는 로직이 이미 띄운다**(`IronRing.Habitats.TileUnlockNotices` → `ToastScreen.Show`): "새 타일: 증기관 · 굴뚝"(`unlock_toast_tiles`), "새 설계도: 철골 창고 · 정비창"(`unlock_toast_recipes`, 구분자 `unlock_name_sep` " · "). 시간 = `CodexUnlocks.json` `_toastSeconds`(4초).
- **UI가 할 일(겹침 방지):** `CodexScreen.OnRecipeUnlocked`는 지금 source가 board/teach가 아니면 "새 레시피: X"(`codex_toast_new`)를 쌓는다 → **source가 `"combo"`면 토스트를 쌓지 말 것**(로직 토스트와 중복). 도감 다시 그리기는 그대로.
- 등급 상승 토스트(`town_tier_up`, EconomyInstaller)에는 원래 레시피 문구가 없음. HUD 등급 배너에 "레시피 해금" 문구가 있으면 지울 것. `ITownTier.UnlockedRecipeIds`는 이제 늘 비어 있음.

**도감 "???" 카드의 부분 재료:** 레시피 재료 타일은 `HabitatsInstaller.Catalog.Get(typeId).TileIds()`(중복 가능, 패턴은 칸 순서) → 각 타일에 `IsTileUnlocked`면 아이템 이름·아이콘, 아니면 "???". 선행 건물이 있는 레시피(`RequiredRecipeOf != null && !HasBuilt(...)`)는 재료가 다 열려도 "???" — "먼저 ○○을 지어야 함" 힌트를 보여도 됨(선택).

**배치 가드:** `ItemPlacement.CanPlace/TryPlace`가 잠긴 타일을 거부한다(`ItemPlacement.IsUnlocked`, ItemsInstaller가 `IsTileUnlocked`로 연결). 회수는 언제나 가능.

**해금표(데이터 `Assets/Scripts/Habitats/Resources/Habitats/CodexUnlocks.json`):** 시작 `tile_boiler, tile_coal, tile_cobble, tile_bunk, tile_bench` / boiler_room→tile_pipe, tile_chimney / coal_yard→tile_girder / cobble_plaza→tile_gaslamp / barracks→tile_tank / iron_depot→tile_gear / water_tower→tile_glass / lamp_street→tile_wire.
시작 시 알려진 레시피: coal_yard, cobble_plaza, boiler_room, barracks (15종 중 4).

**데모(캡처용):** `--unlock-demo --unlock-stage start|first|all` — start = 핫바 5종 그대로, first = 보일러실만 지은 직후(증기관·굴뚝 해금 토스트·반짝임), all = 사슬 끝까지. 거점 hub-1 내부를 자동으로 연다.

**건물 정리(b1228e6):** `lamp_road`·`grand_cogworks`·`cistern`·`toolshop` 삭제(카탈로그 15종). `iron_depot` = 철골3+작업대1, `telegraph_line` = 전신주2+철골1. 도감 분모는 `HabitatCodex.TotalCount`(15)를 쓸 것 — ko.json의 하드코딩 미리보기 "3 / 19"(`ui_sample_codex_title`)가 있으면 편집 모드 샘플일 뿐.
